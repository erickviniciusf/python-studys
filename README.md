# Estudos de Python 🐍

> **EN:** My Python learning log. I'm a JavaScript/Node.js developer learning Python, working through DIO's *Python Fundamentals* track. Every module ends with an exercise built on a real case: the sales and finances of a snack bar I help run.

Este repositório registra meus estudos de Python durante a **Formação Python Fundamentals** da [DIO](https://www.dio.me).

Já trabalho com JavaScript/Node.js ([RiVolto](https://github.com/erickviniciusf) e Stay.o) e estou aprendendo Python para trabalhar com backend, dados e IA. O código daqui é escrito por mim. Uso IA só como tutora, para tirar dúvidas e revisar o código, nunca para gerar a solução.

## 🍔 O caso real: a lanchonete

Em cada módulo faço um exercício baseado numa lanchonete que ajudo a administrar: cardápio, pedidos, delivery e cálculo do lucro. Quando a formação terminar, os exercícios juntos viram a **v0 de um controle financeiro**, a base de um projeto maior.

> Os dados neste repositório são fictícios. Os números reais do negócio não são versionados.

## 📝 Anotações: JavaScript → Python

| JavaScript | Python |
|---|---|
| `array` | `list` |
| `object` | `dict` |
| `for (const x of lista)` | `for x in lista:` |
| `null` | `None` |
| `console.log()` | `print()` |
| `===` | `==` |
